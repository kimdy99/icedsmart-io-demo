# ICEDSmart I/O 配置演示

用于评审自定义事件和 I/O 关系配置流程的交互原型。默认使用 A 版布局，自定义事件通过右侧滑出面板新增和编辑。

## 在线演示

- I/O 关系：https://kimdy99.github.io/icedsmart-io-demo/
- 自定义事件：https://kimdy99.github.io/icedsmart-io-demo/events.html

## 操作

1. 在自定义事件页新增事件，选择设备与输出，为各输出分别设置动作。
2. 在 I/O 关系页选择设备，新增或编辑关系，设置时间表和输入条件，再选择完整自定义事件。
3. 修改事件后，引用该事件的关系自动使用最新定义。

仅包含虚拟设备和示例数据，不连接后台或真实设备。配置保存在当前浏览器标签页的 sessionStorage 中；刷新通常保留，关闭会话后可能重置。访问者之间不共享修改。

这是公开演示，任何拿到链接的人均可访问。仓库仅包含独立演示文件。

## 本地运行

```sh
python3 -m http.server 8765
```

打开 http://127.0.0.1:8765/ 。无需安装前端依赖。

## 检查

```sh
node verify-logic.cjs
```
